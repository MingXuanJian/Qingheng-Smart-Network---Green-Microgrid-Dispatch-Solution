# 青衡智络——微电网多能耦合协同调度方案

本仓库为“青衡智络”iCAN项目代码整理包，主要包括多能流动态分析、碳流追踪与碳核算、改进鲸鱼算法综合调度三部分。

## 文件夹说明

* `00_总说明与技术覆盖`
  项目说明、代码对应关系及文件校验清单。

* `01_核心技术一_多能流动态分析`
  包括数据处理、CNN-LSTM-Attention时序预测，以及风、光、储、氢状态建模。

* `02_核心技术二_图论碳流追踪与碳核算`
  包括BFS碳流分配、DFS路径追踪、储能碳库存和碳核算指标计算。

* `03_核心技术三_改进鲸鱼算法与综合调度`
  包括Logistic-Tent混沌初始化、非线性惯性权重、24小时优化调度、滚动调度和网络校核。

* `04_国际会议论文关联代码`
  存放与EI会议论文相关的共用代码、差异说明及后续补充的论文原始代码。

* `05_桌面软件平台`
  包括数据导入、参数配置、结果展示和报告导出等功能。

* `06_运行配置与演示数据`
  存放配置文件、示例数据、运行脚本和环境依赖。

* `07_测试用例与完整性校验`
  存放算法测试、软件测试及代码完整性检查工具。

* `08_原始完整可运行工程备份`
  保留原始模块结构，建议从该目录解压并运行完整工程。

## 说明

iCAN项目版改进鲸鱼算法与EI论文版IWOA并非完全相同，两部分代码分别归档，不混用实验结果。

本仓库主要用于项目展示、技术复核和团队协作。
