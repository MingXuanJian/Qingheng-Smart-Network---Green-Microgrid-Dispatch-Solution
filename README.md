# 青衡智络——基于碳流追踪的微电网多能耦合协同调度方案

**Qingheng Smart Network — A Coordinated Scheduling Scheme for Multi-Energy Coupled Microgrids Based on Carbon Flow Tracing**

本仓库整理了“青衡智络”iCAN创新创业项目的主要算法代码、桌面软件、运行配置、演示数据、测试程序和技术说明文档。

项目面向风—光—储—氢多能耦合微电网，围绕以下三项核心技术构建代码体系：

1. **微电网多能流动态分析技术**
2. **基于图论碳流模型的微电网减碳量量化分析**
3. **融合改进鲸鱼优化算法的微电网综合调度**

---

## 一、项目技术路线

```text
运行数据接入与质量门控
        ↓
CNN-LSTM-Attention时序预测
        ↓
风—光—储—氢多能状态建模
        ↓
网络潮流计算与有向功率图构建
        ↓
BFS碳流分配与DFS源荷路径溯源
        ↓
储能碳库存和多维碳指标计算
        ↓
碳信号进入综合调度模型
        ↓
Logistic-Tent混沌加权鲸鱼算法寻优
        ↓
24小时风光储氢网荷协同调度
        ↓
滚动执行、跨日状态传递与网络校核
        ↓
桌面平台展示与报告导出
```

三项核心技术不是彼此独立的算法展示，而是按照“**数据—预测—碳流—调度—校核—展示**”形成完整技术链。

## 4.1 数据处理与质量门控


主要功能：

## 4.2 CNN-LSTM-Attention时序预测

主要文件：

```text
data.py
model.py
training.py
metrics.py
forecast_workflow.py
```

其中，`model.py` 实现了由以下结构组成的时序预测网络：

```text
一维时序卷积
    ↓
长短期记忆网络
    ↓
多头自注意力
    ↓
注意力池化
    ↓
多步预测输出
```

各文件功能如下：

* `data.py`：构造训练、验证和测试时序窗口；
* `model.py`：定义CNN-LSTM-Attention网络结构；
* `training.py`：完成模型训练、验证、早停和权重保存；
* `metrics.py`：计算MAE、RMSE、sMAPE等预测指标；
* `forecast_workflow.py`：串联数据准备、基线预测、神经网络训练和结果导出。

当前工程已经形成负荷、光伏等时序变量的预测流程。SOC、氢储量等变量主要在综合调度模型中作为跨时段状态递推计算，不应将其全部表述为已经完成真实数据训练的神经网络预测量。

```text
├─ 01_碳流追踪算法

├─ 03_四项碳核算指标
└─ 04_碳流与调度衔接
```

## 5.1 碳流追踪算法

核心文件：

```text
tracer.py
```

主要实现：

* 根据支路有功功率判断潮流方向；
* 将微电网转换为加权有向图；
* 反向潮流出现时自动调整边方向；
* 使用Kahn-BFS获得网络拓扑顺序；
* 对无环网络进行逐层碳流分配；
* 使用DFS递归回溯源—荷可行路径；
* 计算不同电源对不同负荷的功率贡献；
* 对存在有向环的网络使用线性方程或最小二乘方法求解；
* 检查节点功率分配和碳流守恒残差。

## 5.2 储能碳库存与绿电标签

核心文件：

```text
reservoir.py
```

该模块用于记录储能充放电过程中的能量来源和碳属性，主要包括：

* 电池储能碳库存；
* 氢储能碳库存；
* 绿色电量库存；
* 充电过程碳强度继承；
* 放电过程碳属性释放；
* 储能状态和碳标签跨时段传递；
* 滚动调度过程中的跨日状态连续。

该设计使储能不再被简单视为“零碳电源”，而是根据其实际充电来源追踪相应的碳属性。

## 5.3 四项碳核算指标

核心文件：

```text
metrics.py
```

代码中包含以下四类项目碳核算指标：

1. **绿电自用率**
2. **单位供能碳强度**
3. **低碳储能贡献率**
4. **可核算减排量**

四项指标分别从效率、强度、贡献和总量等角度描述微电网的低碳运行效果。

## 5.4 碳流与调度衔接

核心文件：

```text
pipeline.py
```

该模块负责连接潮流、碳流和优化调度过程，将以下信息形成调度输入：

* 各电源分时碳强度；
* 各负荷分时碳排放；
* 储能碳库存；
* 绿电标签；
* 单位供能碳强度；
* 可核算减排量。

由此形成“碳流核算结果反向指导低碳调度”的闭环。
